Last updated: May 19, 2026

Overview

Too-Tee Learning is a plain static educational website for kids, families, and adults who want to learn about teeth. We designed this site to be simple and privacy-conscious.

Information We Collect

We do not collect personal information directly through this website. The site does not include user accounts, checkout, comments, newsletter signup, embedded forms, or any other feature that asks visitors to submit personal information.

Cookies and Analytics

We do not use cookies, Google Analytics, advertising trackers, pixels, or behavioral analytics tools on this website.

Static Site Hosting

This site is hosted as a static website on GitHub Pages. Like most web hosting providers, GitHub may process basic technical information when pages are requested, such as IP address, browser information, request time, and requested URL. That processing is handled by GitHub as the hosting provider and is used for security, reliability, and operation of the service.

Third-Party Services

The site may load web fonts from Google Fonts because the design uses externally hosted font files. When your browser requests those font files, Google may receive basic technical request information. We do not use Google Analytics or Google advertising services.

Children's Privacy

Too-Tee Learning provides educational content that may be useful for children, but the website does not ask children to create accounts, submit names, send messages, or provide personal information.

Links to Other Websites

Some pages may link to other websites or resources. Those websites are controlled by their own operators and may have their own privacy practices. This policy applies only to the Too-Tee Learning website.

Changes to This Policy

We may update this Privacy Policy if the website changes, such as adding forms, analytics, email signup, or other interactive features. Any updates will be posted on this page with a revised date.
